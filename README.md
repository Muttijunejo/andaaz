# ANDAAZ

ANDAAZ is a clothing-brand storefront website for a Pakistani fashion label — an online shop with a product catalogue, a shopping bag, WhatsApp checkout and a customer "share your look" wall.

## Features

- **Product catalogue** — browse outfits with filters for category, colour, size and price range, plus a quick product view
- **Collections** — Festive Picks, the Eid Family Edit, bestsellers and new arrivals
- **Shopping bag** — add items, adjust quantities and check out through WhatsApp
- **Cash on delivery** — COD available all over Pakistan
- **Share your look** — customers post photos of their outfits with their Instagram handle on a community wall
- **Contact** — one-tap WhatsApp chat with the store

## Tech stack

- React 19 + TypeScript, styled with Tailwind CSS
- TanStack Query for data fetching
- Bun-powered server actions
- Drizzle ORM with a SQLite database
- Zod validation

## Project layout

- `client/` — React front end
- `server/` — server actions and database schema
- `drizzle/` — database migrations
